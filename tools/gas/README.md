# GAS (Google Apps Script) の設定手順

フォーム → GAS → GitHub Actions の橋渡し部分です。一度だけ行います。所要 20〜30 分。
設計の全体像は [ADR-0001](../../docs/adr/0001-form-to-github-update.md) を参照。

## 0. 用意するもの

- Google アカウント (フォームと GAS の持ち主になる)
- GitHub の fine-grained トークン
  1. https://github.com/settings/personal-access-tokens → Generate new token
  2. Repository access: Only select repositories → このリポジトリ
  3. Permissions → Repository permissions → **Contents: Read and write** (他は不要)
  4. 有効期限は 1 年など長めに。期限が来たら作り直してスクリプトプロパティを更新する
- 合言葉 (NOTIFY_TOKEN): 適当な長いランダム文字列。GAS と GitHub の両方に同じ値を入れる

## 1. GAS プロジェクトを作る

1. https://script.google.com → 「新しいプロジェクト」
2. 左上の名前を「HP更新フォーム」などに変更
3. エディタの `Code.gs` の中身を全部消し、[Code.gs](Code.gs) の内容を貼り付けて保存

## 2. スクリプトプロパティを設定する

左メニュー「プロジェクトの設定」(歯車) → 一番下「スクリプトプロパティ」→ 追加

| プロパティ | 値 |
|---|---|
| `GITHUB_TOKEN` | 上で作ったトークン |
| `GITHUB_REPO` | `NorikoOno/senju-hp-sample` |
| `ALLOWED_EMAILS` | 送信を許可するメール。最初は自分のアドレスだけ |
| `NOTIFY_TOKEN` | 合言葉 |
| `SITE_URL` | `https://norikoono.github.io/senju-hp-sample/` |

## 3. setup を実行する

1. エディタ上部の関数選択で `setup` を選び「実行」
2. 初回は権限の確認が出る。「権限を確認」→ 自分のアカウント → 「詳細」→「(安全ではないページ) に移動」→ 許可
   (自分で書いたスクリプトなので Google の警告が出るが問題ない)
3. 実行ログに **編集用URL** と **回答用URL** が出る。両方控えておく

## 4. 「写真」の質問を手で追加する

スクリプトからはファイルアップロードの質問を作れないため、ここだけ手作業です。

1. 編集用URLを開く
2. セクション「生徒の作品を追加」の中で「展覧会の一言」の下に質問を追加
3. 質問文: `写真` (この文字どおりに)
4. 種類: **ファイルのアップロード**
5. 「複数ファイルを許可」をオン、最大ファイル数 10、ファイル形式を「画像」のみ、最大サイズ 10 MB

## 5. ウェブアプリとして公開する (結果メール用)

1. エディタ右上「デプロイ」→「新しいデプロイ」
2. 種類の選択 (歯車) → 「ウェブアプリ」
3. 次のユーザーとして実行: **自分**、アクセスできるユーザー: **全員**
4. 「デプロイ」→ 表示された **ウェブアプリの URL** をコピー

## 6. GitHub に secrets を登録する

リポジトリ → Settings → Secrets and variables → Actions → New repository secret

| 名前 | 値 |
|---|---|
| `NOTIFY_URL` | 手順 5 のウェブアプリ URL |
| `NOTIFY_TOKEN` | 合言葉 (GAS と同じ値) |

## 7. 動作確認

1. スマホで回答用URLを開き、「お知らせを追加」でテスト文を送る
2. 1〜3 分でメールが届き、サイトのお知らせに反映されていることを確認
3. 「直前の更新を取り消す」を送り、元に戻ることを確認
4. 続けて「開講日カレンダー」「生徒の作品を追加」「生徒の作品を削除」も試す

エディタで `sendTest` を実行しても、フォームを経由せずに同じテストができます。

## 8. 作業者に引き継ぐ

1. スクリプトプロパティ `ALLOWED_EMAILS` に作業者の Google アカウントのメールをカンマ区切りで追加
2. 回答用URLを共有してもらい、スマホのホーム画面に追加してもらう
3. 必要なら、編集用URLからフォームの共同編集者にも追加する

## よくあるトラブル

| 症状 | 原因と対処 |
|---|---|
| 送信しても何も起きない | 送信者のメールが `ALLOWED_EMAILS` にない。GAS の「実行数」にログが残る |
| 「GitHub API エラー 401/403」のメール | トークンの期限切れか権限不足。トークンを作り直す |
| メールが来ないがサイトは更新されている | `NOTIFY_URL` / `NOTIFY_TOKEN` の設定違い。Actions のログの Notify を見る |
| 消すお知らせ・消す作品の選択肢が古い | エディタで `refreshChoices` を実行。毎朝 5 時にも自動で更新される |
| コードを直したのにウェブアプリの動きが変わらない | 「デプロイを管理」→ 鉛筆 → バージョン「新バージョン」で再デプロイ |
